# 实验3：文本情感分析

## 概述

本实验在 Rotten Tomato 影评数据集上构建了一个情感分析流程。我从零实现了
特征提取器和基于 hinge loss 训练的线性分类器，并在此基础上对比了 6 种
文本表示方法——从统计特征（BOW、N-gram、TF-IDF）到词/句向量（GloVe、
Doc2Vec）以及上下文预训练模型（BERT）。此外，我还用 SVM 替换手写线性
分类器，对比了不同优化器的表现。

## 我做了什么

### Hinge loss 推导与实现
- 推导了 hinge loss 对权重向量 `w` 的反向传播公式。
- 实现了线性分类器（`learnPredictor`）及其 SGD 更新。

### 特征提取
实现了 6 种文本表示方法：
- **BOW** — 0-1 词袋向量。
- **N-gram (N=2)** — bigram 统计特征。
- **TF-IDF** — 词频-逆文档频率加权。
- **Word2Vec (GloVe 100d)** — 预训练 GloVe 词向量，句子向量取词向量平均。
- **Doc2Vec** — 在任务数据上训练的 gensim Doc2Vec。
- **BERT** — 以 [CLS] token 表示作为句子向量。

### 分类器对比
- 在所有特征上用 hinge loss + SGD 训练简单线性分类器。
- 在相同特征上用 SVM 替换分类器，并对比 ROC 曲线。

## 关键结果

| 特征 | Accuracy | F1 | AUC |
|------|----------|-----|-----|
| BOW | 0.7364 | 0.7376 | 0.8080 |
| N-gram (N=2) | 0.6705 | 0.6741 | 0.7378 |
| TF-IDF | 0.7434 | 0.7396 | 0.8213 |
| Word2Vec (GloVe 100d, 平均) | 0.7290 | 0.7133 | 0.8083 |
| Doc2Vec | 0.6497 | 0.6665 | 0.6946 |
| **BERT + SVM** | **0.7932** | **0.7879** | **0.8726** |

最佳结果：**BERT [CLS] + SVM，Accuracy 0.7932**。

## 分析

- **BOW**：测试集在 epoch 10 左右收敛，而训练损失仍在下降——明显过拟合。
- **N-gram**：比 BOW 收敛更快，但泛化更差。情感往往由单个词表达，
  且本数据集较小（3,554 条），bigram 否定表达过于稀疏。
- **TF-IDF**：训练错误率在第 1 个 epoch 就接近收敛，效果略优于 BOW
  （0.7434 vs 0.7364）。
- **Word2Vec (GloVe)**：训练集与测试集曲线非常接近，泛化能力强，
  得益于预训练词向量；但整体指标相比统计模型没有明显优势，
  且召回率偏低。
- **Doc2Vec**：仅在较小的任务数据集上训练，表现最差（0.6497），
  甚至低于统计模型。
- **SVM vs. 线性分类器**：本实验中 SVM 没有超过简单线性分类器，
  尤其在 GloVe 特征上。GloVe 数值分布与 SVM 默认优化器设置不匹配，
  而 SGD 更稳定。
- **BERT + SVM**：明显最佳（0.7932），验证了上下文预训练表示的优势。

### 模型特点比较
| 模型 | 预训练/构造方式 | 特征本质 | 本实验表现 |
|------|----------------|----------|-----------|
| BOW / N-gram / TF-IDF | 无预训练，基于训练集统计构造 | 词频，无语义理解 | 较好 |
| Word2Vec / GloVe | 基于词共现的静态预训练 | 静态词义，忽略上下文 | 较好 |
| Doc2Vec | 在任务数据上自训练 | 文档级主题向量，忽略局部词序 | 较差 |
| BERT | 大规模语料上的掩码语言模型+下一句预测 | 深层上下文语义，动态表示 | 很好 |
